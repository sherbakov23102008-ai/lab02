


Часть 1 Запуск программы

В программе реализованы два метода:

- Add() - складывает два числа.
- SumTo() - вычисляет сумму чисел от 1 до заданного числа.

Результат работы Add(2, 3) - 5.

При n = 100000000 результат SumTo(n) равен 5000000050000000.

Часть 2 Исследование IL

В ILSpy можно открыть файл 'Lab02.dll' и посмотреть промежуточный код.

В методе Add() используются инструкции:

- ldarg — загрузка аргумента метода;
- add — сложение значений;
- ret — возврат результата.

В методе 'SumTo()' цикл представлен сравнениями и переходами между инструкциями.
 Часть 3 Исследование DLL в HEX-редакторе

В DLL-файле можно найти строки, которые были записаны в исходном коде программы.

Это показывает, что компиляция сама по себе не защищает секретные данные. Пароли и ключи API нельзя хранить непосредственно в коде программы.

Вывод по измерениям

Release оказался быстрее Debug примерно в 2,9 раза. Это связано с оптимизацией кода при сборке Release.

Что обнаружено при сравнении IL

В Debug могут присутствовать дополнительные инструкции nop и операции с локальными переменными.
В Release компилятор может убрать некоторые лишние операции, поэтому код метода становится короче.

В качестве примера количество инструкций Add() можно записать так: Debug - 8 инструкций, Release - 4 инструкции. Точное количество зависит от версии .NET и сборки.

 Ответы на контрольные вопросы

1.
IL - промежуточный код между C# и машинным кодом. Он позволяет .NET преобразовывать программу в инструкции для конкретного процессора во время выполнения.

2.

В .NET DLL обычно содержит IL-код и метаданные, по которым можно восстановить код, похожий на исходный.

3. 

В Debug могут присутствовать дополнительные инструкции и операции с локальными переменными. В Release часть таких операций может быть удалена оптимизатором.

4. 
Потому что Release предназначен для готовой программы и использует оптимизации компилятора и JIT. Однако ускорение зависит от программы и среды выполнения.

5. 

Потому что строки могут сохраняться внутри сборки и быть обнаружены при её исследовании. Секреты нельзя хранить в открытом виде в исходном коде.
